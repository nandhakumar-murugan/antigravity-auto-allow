# Antigravity Auto-Allow Companion

A floating on-screen desktop tool created specifically to solve confirmation fatigue when running agent tasks in Google Antigravity.

## How It Works
1. **Review First**: Review your plan or implementation steps in Antigravity.
2. **Turn On**: Click the green **`START AUTO-ALLOW`** button (or press **`F9`**).
3. **Hands-free Execution**: As Antigravity runs tasks, whenever the permission confirmation dialog appears, the tool automatically detects the dialog and clicks **Submit** (Option 1: "Yes, allow this time").
4. **Pause Anytime**: Press **`F9`** or click **`STOP AUTO-ALLOW`** whenever you want manual control back.

## Features
- **Always on Top**: Floats unobtrusively on top of your windows.
- **Draggable**: Drag it by the top bar to place it anywhere on screen.
- **Global Hotkey (`F9`)**: Toggle ON/OFF instantly from anywhere without switching windows.
- **Mode Selection**:
  - `Allow This Time (Opt 1)`: Default mode. Approves each command as it comes.
  - `Always Allow (Opt 4)`: Selects option 4 to permanently whitelist recurring actions.
- **Audible Chime**: Subtle sound notification each time an approval is submitted.
- **Counter**: Displays how many actions were approved automatically.
